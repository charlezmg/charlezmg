Short-form content workflow

Short-form publishing workflow system

A repeatable workflow for producing, organizing, scheduling, and publishing short-form content for TikTok and YouTube Shorts.

Operational objective

A structured workflow for short-form publishing

The workflow used defined formats, batch production, platform-specific adjustments, and a fixed publishing schedule instead of creating and posting content reactively.

  • Defined content formats
  • Controlled script length
  • Batch production
  • Platform-specific adaptation
  • Consistent publishing schedule

Content format rules

Keeping the format consistent

  • 4 to 6 slides per TikTok video
  • About 70 characters per slide
  • Dialogue formatted as a monologue
  • The first slide served as both the hook and thumbnail
  • The sequence built tension from one slide to the next

Content structure

A consistent structure for every video

Scripts followed predefined rules so the resulting videos stayed consistent in length, structure, and visual format.

TikTok publishing format

  • Slide-based pacing
  • Hook-first visual layout
  • Mobile-first publishing
  • Three-batch publishing schedule
  • Weekly batches prepared in advance

Content was prepared in batches instead of being created and posted one piece at a time.

Adapting the workflow for different platforms

The same workflow, adapted for each platform

  • Approximately 20-second vertical videos
  • The first frame used a split layout with an upper text block and dual-video background
  • The second frame used a simple slide format
  • Existing content was adapted without changing the underlying workflow
  • Background music was added through YouTube

The format changed, but the workflow stayed the same

Workflow and asset flow

From idea to published video

  1. Idea
  2. Script using the defined format
  3. Canva template
  4. Export
  5. Google Drive
  6. Desktop scheduling
  7. Mobile finalization
  8. Content logging

Google Sheets tracking

Tracked for each video

  • Title
  • Description and hashtags
  • Canva template link
  • Posting date and time
  • Publishing status

Canva templates also served as a visual reference for keeping the content format consistent.
