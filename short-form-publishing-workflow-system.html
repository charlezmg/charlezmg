The Mad Theorist

Short-form publishing workflow system

Designed and executed a repeatable short-form production system adaptable across TikTok and YouTube Shorts while maintaining workflow integrity.

Operational objective

Constraint control over reactive posting

Build a structured short-form publishing engine focused on constraint control, format governance, and disciplined execution.

  • Defined format rules
  • Controlled script length
  • Batch production
  • Platform-aware adaptation
  • Fixed publishing cadence

Core playbook & format rules

Format constraints enforced

  • 4–6 slide limit per TikTok video
  • Approximately 70 characters per slide
  • Dialogue presented in a monologue format
  • Slide 1 engineered as both the hook and thumbnail
  • Narrative escalation designed to reflect tension

Structural governance

Predictable output, predictable visuals

Scripts were generated under predefined constraints to ensure predictable output and visual consistency.

TikTok format execution

  • Slide-based dialogue pacing
  • Hook-first visual hierarchy
  • Mobile-native publishing
  • Three-batch publishing growth window
  • Weekly batching prepared in advance

Content was produced under fixed structural rules rather than reactive posting.

Cross-platform format adaptation

Same workflow. Different output layer

  • Approximately 20-second vertical format
  • Frame 1 used a static split layout with an upper text block and dual-video background
  • Frame 2 used a simple slide format
  • Existing content was adapted while preserving the workflow structure
  • Background music was applied natively through YouTube

Format changed. Workflow remained intact
